## 三、本轮修复（均属自检工具，非产品代码）

1. **`tools/build-portable.js` 排除清单遗漏**
   `APP_SKIP` 漏了 `_audio-e2e.js`（`_` 前缀本应排除，否则会被打进发布包）。已补上，并一并加入 `_node-shim.js`、`_ui-*.png`、`_nodetest_prof`。现状：`tools/` 下含下划线但未列入跳过 = **0**。

2. **`tools/probe.js` 合集反向验证崩溃**
   原代码直接读 `season.sections[0].archives[0]`，但 **B站 新版合集条目字段已由 `sections[].archives` 改为 `sections[].episodes`**，导致总集数被误算成 0 后数组越界崩溃。改为 `s.episodes || s.archives` 并加空值防御。修复后正确输出 `总集数=22`。
   > 产品代码 `src/main/resolver.js` 早有 `sec.episodes || sec.archives || []` 兼容，**未受影响** —— probe.js 才是过时的一方。

## 四、新增工具

**`tools/_node-shim.js`（通用无 GUI 运行器）**
把此前 `_mp3-e2e-node.js` 里的 electron 桩抽成通用入口，可在此类环境下运行任何 `require('electron')` 的自检脚本：

```bash
node tools/_node-shim.js selftest.js      # 视频通路（双流 + 混流）
node tools/_node-shim.js parse-test.js    # 解析层
node tools/_node-shim.js _audio-e2e.js    # 音频通路（另一实现）
```
不支持 `douyin-test.js` / `douyin-browser-probe.js`（依赖真 Chromium 隐藏窗口 + CDP）。原 `_selftest-node.js` 已删除并入此入口。
